# 3.4 Azure Monitoring Tools

## Azure Monitoring Overview

### Definition
Azure monitoring provides comprehensive solutions for collecting, analyzing, and acting on telemetry data from your cloud and on-premises environments to maximize performance and availability.

### Key Monitoring Concepts
- **Telemetry**: Data collected from applications and infrastructure
- **Metrics**: Numerical values that describe system performance
- **Logs**: Records of events and activities
- **Alerts**: Notifications based on monitoring conditions
- **Dashboards**: Visual representations of monitoring data

### Monitoring Data Types

#### Platform Metrics
- **Automatically Collected**: No configuration required
- **Resource-Specific**: CPU, memory, network, storage
- **Service-Specific**: Request rates, error rates, response times
- **Retention**: 93 days by default

#### Platform Logs
- **Activity Logs**: Subscription-level events
- **Resource Logs**: Service-specific operational data
- **Azure AD Logs**: Authentication and directory activities
- **Retention**: Varies by log type

#### Custom Data
- **Application Telemetry**: Custom application metrics and logs
- **Custom Metrics**: Business-specific measurements
- **Custom Logs**: Application and system logs

#### KQL (Kusto Query Language) Examples
```kql
// Basic log query
AzureActivity
| where TimeGenerated > ago(24h)
| where Level == "Error"
| summarize count() by ResourceProvider
| order by count_ desc

// Performance analysis
Perf
| where TimeGenerated > ago(1h)
| where ObjectName == "Processor" and CounterName == "% Processor Time"
| summarize avg(CounterValue) by Computer
| order by avg_CounterValue desc

// Application logs analysis
AppTraces
| where TimeGenerated > ago(6h)
| where SeverityLevel >= 3
| summarize count() by tostring(Properties.Category), bin(TimeGenerated, 1h)
| render timechart

// Security events
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4625  // Failed logon attempts
| summarize FailedAttempts = count() by Account, Computer
| where FailedAttempts > 10
| order by FailedAttempts desc
```

### Azure Monitor Alerts

#### Alert Types

##### Metric Alerts
```
Configuration:
├── Scope: Target resources to monitor
├── Condition: Metric + operator + threshold
├── Evaluation: How often to check
├── Action: What to do when triggered
└── Description: Alert details and context

Example:
- Resource: Web App "ProductionSite"
- Metric: Average response time
- Condition: Greater than 2 seconds
- Evaluation: Every 5 minutes
- Action: Email admin team + SMS to on-call
```

##### Log Search Alerts
```
KQL-based Alerts:
├── Search Query: KQL query to identify conditions
├── Time Period: How far back to search
├── Frequency: How often to run query
├── Threshold: Number of results to trigger alert
└── Suppression: Prevent duplicate alerts

Example Query:
AzureActivity
| where Level == "Error"
| where ResourceProvider == "Microsoft.Compute"
| where TimeGenerated > ago(15m)
| summarize count()
```

##### Activity Log Alerts
```
Subscription-level Alerts:
├── Administrative Operations: Resource creation/deletion
├── Service Health Events: Azure service issues
├── Resource Health Events: Individual resource health
├── Autoscale Events: Scaling operations
└── Security Events: Security-related activities

Example Scenarios:
- Alert when VM is deleted
- Notify when resource group is created
- Alert on service health incidents
- Monitor policy compliance violations
```

Action Group Components:

#### Alert Rules Configuration Example
```json
{
  "name": "High CPU Alert",
  "description": "Alert when VM CPU exceeds 80%",
  "severity": 2,
  "enabled": true,
  "scopes": ["/subscriptions/.../Microsoft.Compute/virtualMachines/MyVM"],
  "condition": {
    "metricName": "Percentage CPU",
    "operator": "GreaterThan", 
    "threshold": 80,
    "timeAggregation": "Average",
    "windowSize": "PT5M",
    "evaluationFrequency": "PT1M"
  },
  "actions": [
    {
      "actionGroupId": "/subscriptions/.../actionGroups/AdminTeam"
    }
  ]
}
```

#### Kusto Queries for Application Insights
```kql
// Application performance overview
requests
| where timestamp > ago(24h)
| summarize 
    RequestCount = count(),
    AvgDuration = avg(duration),
    PercentileP95 = percentile(duration, 95)
    by bin(timestamp, 1h)
| render timechart

// Top failing operations
requests
| where timestamp > ago(24h) and success == false
| summarize FailureCount = count() by name, resultCode
| order by FailureCount desc
| take 10

// Database dependency analysis
dependencies
| where timestamp > ago(6h)
| where type == "SQL" 
| summarize 
    CallCount = count(),
    AvgDuration = avg(duration),
    FailureRate = countif(success == false) * 100.0 / count()
    by name
| order by CallCount desc

// User behavior analysis
pageViews
| where timestamp > ago(7d)
| summarize PageViews = count() by tostring(client_CountryOrRegion)
| order by PageViews desc
| take 20
```
